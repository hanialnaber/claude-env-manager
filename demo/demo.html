Claude Code on the web (cloud sessions)

Cloud sessions run on Anthropic's machines, so they never read the User or Project local settings on this computer. There's no public API to set their variables, so add them once on the cloud environment:

  1. Open Claude Code on the web and go to the settings of the environment your sessions use.
  2. Find Environment variables. They take .env format, one KEY=value per line.
  3. Paste the lines you copy below and save.
  4. Start a new session. Running sessions keep their old values until their machine is rebuilt.
  5. Check it arrived with the one-liner at the bottom. It prints the length, never the value.
Good to know. Anyone who can use that environment can read its variables, and any command Claude runs can see them. For an API key that only needs to reach one service, the docs suggest a network secret on the environment instead, which can't be read inside the session. A repo's shared .claude/settings.json is read in cloud sessions only for a single repo outside a Claude project, so don't rely on it, and never commit keys there.
